# Run SimuPBX on your desktop — live, real time

One command. Calls ring your softphone, transcripts stream live, missed calls
drop WhatsApp follow-ups into the inbox, Zuri answers with real AI.

## Requirements (inside Ubuntu/WSL)

- Node.js 20+ **installed in Ubuntu** (`which node` must show `/usr/bin/node`)
- Docker running (`docker ps` works — Docker Desktop with WSL integration is fine)

## Start it

```bash
cd ~/simupbx-app/simupbx
git pull
bash run-desktop.sh
```

Open **http://localhost:3000**, log in with `admin@simupbx.local` / `simupbx`,
go to the **Phone** tab, and wait ~30 seconds — a call will ring. Answer it and
watch the live transcript + Zuri suggestions stream in the side panel. Let one
ring out → check **Inbox** for the automatic follow-up and **Calls** for the
missed-call record. Everything you see is the real engine writing real database
rows over a real WebSocket — the same pipeline live calls use.

### Want Zuri to answer with real AI?

```bash
export ANTHROPIC_API_KEY=sk-ant-...   # from platform.claude.com (has free credit)
bash run-desktop.sh
```

Now the Zuri tab's test console (English + Swahili) and call summaries are
generated by Claude for real.

### Run it as a native desktop app

```bash
bash run-desktop.sh --app
```

This opens SimuPBX in its own window (Electron). On Windows 11, WSL GUI apps
work out of the box (WSLg). If the window doesn't appear, just use the browser
at localhost:3000 — same app. You can also install it from the browser: menu →
*Install SimuPBX* (it's a PWA) — that gives you a desktop icon + its own window
with zero extra setup, honestly the smoothest option on Windows.

## Going live with your real +254 number

The desktop engine and the live telco path are the same code — going live is
configuration, not new software:

1. **VPS** (4 GB Ubuntu, ~$6/mo) with your domain → `make up` (see README).
2. **Africa's Talking**: buy a Kenyan voice number (~KES 1,000/mo, needs KYC),
   set its voice callback URL to `https://your-domain/webhooks/at/voice`.
3. Put your AT + Daraja + Anthropic keys in `.env`, restart.
4. Dial the number from your Safaricom line → Zuri/IVR answers → your softphone
   rings. Full phase-by-phase script: **TESTING.md**.

Quick preview without a VPS: you can point Africa's Talking's **sandbox** at
your desktop with a free tunnel:

```bash
# terminal 3
npx cloudflared tunnel --url http://localhost:4000
```

Copy the printed `https://….trycloudflare.com` URL into your AT sandbox app's
voice callback, then place calls from AT's simulator — your desktop answers
them with the real IVR XML. (Real +254 calls still need a purchased number.)

## Troubleshooting

| Symptom | Fix |
|---|---|
| `CMD.EXE was started…UNC paths` | You're on Windows Node — install Node inside Ubuntu (see main README) |
| Port 5432 already in use | Another Postgres is running: `docker ps`, stop it, or edit docker-compose.dev.yml |
| Phone tab stays "Demo mode" | API not up — check terminal for errors, then reload the page |
| No calls ringing | Wait 30–60s after "SimuPBX is running LIVE"; check the API terminal shows `SIMULATE=1` |
